# Roadmap

The current development line is `v0.1.0-dev.0`.

The authoritative plan, with scope, phase order, exit criteria and acceptance tests, is [docs/program/PLAN.md](docs/program/PLAN.md). Progress and evidence are in [docs/program/CHECKLIST.md](docs/program/CHECKLIST.md).

| Phase | Theme | Status |
|---|---|---|
| 0 | Baseline import and test run | Done |
| 1 | Product identity migration | In progress |
| 2 | Skill package and per-agent installation | Planned |
| 3 | Natural-language creation, schemas, knowledge packs | Planned |
| 4 | Review, simulation, cost, export, comparison | Planned |
| 5 | Interactive architecture workbench | Planned |
| 6 | Showcase architectures and benchmarks | Planned |
| 7 | Distribution readiness and acceptance | Planned |

## Not planned

- A hosted service. Artifacts stay standalone offline HTML files.
- Measured performance claims. Simulations are analytical models and are labelled as such.
