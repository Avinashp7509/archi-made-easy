# Roadmap

The current stable version is `v1.0.0`.

The authoritative plan, with scope, phase order, exit criteria and acceptance tests, is [docs/program/PLAN.md](docs/program/PLAN.md). Progress and evidence are in [docs/program/CHECKLIST.md](docs/program/CHECKLIST.md).

| Phase | Theme | Status |
|---|---|---|
| 0 | Baseline import and test run | Done |
| 1 | Product identity migration | Done |
| 2 | Skill package and per-agent installation | Done |
| 3 | Natural-language creation, schemas, knowledge packs | Done |
| 4 | Review, simulation, cost, export, comparison | Done |
| 5 | Interactive architecture workbench | Done |
| 6 | Showcase architectures and benchmarks | Done |
| 7 | Distribution readiness and acceptance | Done locally; publication waits for the owner (see docs/program/release/LAUNCH.md) |

## Not planned

- A hosted service. Artifacts stay standalone offline HTML files.
- Measured performance claims. Simulations are analytical models and are labelled as such.
