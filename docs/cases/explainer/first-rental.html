第一次在大城市租房，签合同前要确认哪些事？

长图

答

结论

核心是三件事：确认人、确认房、确认钱。核实房东身份和产权，把关键条款写进合同，所有付款和交接留证据。

  1. 签约前核对房东身份和产权，拒绝只靠口头承诺。
  2. 租金、押金、租期、违约、维修责任必须写进合同。
  3. 付款走可留痕的方式，交接时逐项验房拍照。

适用于中国大陆城市普通住宅整租或合租首次签约

1

签约前按什么顺序确认？

  • 核对身份和产权 id
  • 签约身份已核实？ ok

  • id → ok
  • ok → terms · 是
  • ok → walk · 否
  • pay → check
  • see → id
  • terms → pay
  1. 实地看房 ↗

    晚上和周末各看一次；测采光、噪音、水压、手机信号；查通勤时间。

  2. 核对身份和产权 ↗

    看身份证原件和房产证；核实签约人是产权人，或持有产权人授权委托书的代理人。

  3. 条款写进合同 ↗

    为减少争议，将关键承诺写进合同或补充条款，并由双方确认。

  4. 付款并留凭证 ↗

    转账备注用途；要求收据，或在合同里注明已收金额。

  5. 逐项验房拍照 ↗

    水电燃气表读数、家具家电、已有破损全部拍照存档。

2

合同里必须写清哪些条款？

条款要确认什么常见坑
租金和付款金额、支付周期、收款账户是房东本人风险高收款人不是房东
押金金额、退还条件、退还时限风险高以卫生费、损耗费名义克扣
租期和退租起止日期、提前退租违约金注意违约扣全部押金
维修责任家电、水管、电路坏了谁修谁付钱注意全部推给租客
转租和续租能否转租、续租时涨租幅度注意禁止转租又不让退租
杂费承担水电气、物业、网费、取暖谁付注意上任租客的欠费算到你头上

签约当天核对什么？

房东身份证
原件核对，姓名与房产证一致
房产证或不动产权证
核对房屋地址和产权人
代理人签约
须有产权人签字的授权委托书
首笔付款
押金加首期租金，金额写进合同
中介费
常见为半个月到一个月租金，事先说定（经验值）

这些情况直接放弃

只给看照片、不让实地看房，还催你先交定金锁房。 拿不出产权证明，或二房东没有原房东同意转租的书面文件。 要求现金或转账到第三方账户，且不给收据。 新装修房有刺鼻气味，或明显是隔断间、群租房。
