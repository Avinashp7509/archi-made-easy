# Changelog

All notable changes to Archi-Made-Easy are recorded here. Versions follow [Semantic Versioning](https://semver.org/). Unreleased work uses a `-dev.N` prerelease version.

## [Unreleased]

Development identity: `v0.1.0-dev.0`

- **New product identity.** Archi-Made-Easy is established from an Apache-2.0 open-source foundation. See `NOTICE` and `ATTRIBUTION.md`.
  - The skill, its CLI (`archi-made-easy`), its JavaScript namespace (`ArchiMadeEasy`), its environment variables (`ARCHI_MADE_EASY_*`), its template markers, packages and release archive all carry the new name.
  - Documents written for the original software validate and render unchanged.
- **Update checks are off until a release host is configured.** `skill-release.json` carries no update manifest, so the skill makes no network request to look for updates.
- **Origin records not carried over.** The original project's journal, review evidence, translated READMEs, community, sponsor and donation material, and contributor tooling are not part of this repository.
